# SHRI Gifting Studio

Build a responsive SHRI Online Gift Shop inspired by the attached references. Use a premium navy-blue and gold visual system; retain a simple, polished structure. Create the public storefront with a reference-inspired hero/banner, brand/logo treatment, category browsing for Birthday, Anniversary, Surprise, Kids, and All Occasion, product cards (image, name, price, View and WhatsApp Order), a prominent WhatsApp order CTA, address/contact details, and Facebook link/icon CTA in header and footer. WhatsApp buttons must work on mobile and desktop and open WhatsApp using 9042770400 and 9042870400 with a pre-filled product name, price, and quantity message. Enable Lovable Cloud first, then create a secure admin login and blue/gold admin dashboard. Admin can create, edit, and delete products, including category, name, price, description, stock, and multiple JPG/PNG/JPEG product images with previews; uploaded products must automatically appear in the storefront. Ensure secure access control, responsive mobile/tablet/desktop layouts, clean subtle premium animations, and functional buttons. Use the reference imagery as brand/design inspiration without overcomplicating the experience.
